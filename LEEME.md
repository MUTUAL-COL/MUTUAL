# MUTUAL – sitio web

Sitio estático (HTML + CSS + JS, sin instalar nada). La página de inicio es `index.html`.

## Publicar en Netlify
1. Entrar a https://app.netlify.com con la cuenta de MUTUAL → **Add new site → Import an existing project → GitHub**.
2. Elegir este repositorio (`MUTUAL`).
3. En "Build command" dejar vacío. En "Publish directory" escribir `.` (un punto).
4. **Deploy**. Cada cambio que se suba a este repositorio se publica solo.
